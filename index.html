Política de Privacidade

Introdução

O aplicativo Controdata valoriza a privacidade dos seus usuários. Esta política de privacidade explica como tratamos as informações fornecidas pelos usuários.

Coleta de Dados

O Controdata não coleta dados pessoais dos usuários, exceto pelo username (nome de usuário) e senha necessários para acesso ao aplicativo.

Uso das Informações

O username e a senha são utilizados exclusivamente para autenticação e acesso ao aplicativo. Nenhuma outra informação pessoal é coletada, armazenada ou compartilhada.

Compartilhamento de Dados

O Controdata não compartilha, vende ou transfere qualquer dado dos usuários a terceiros.

Segurança

Adotamos medidas de segurança para proteger o username e a senha dos usuários contra acesso não autorizado.

Alterações na Política

Esta política pode ser atualizada periodicamente. Recomendamos que os usuários revisem esta página regularmente para se manterem informados sobre possíveis alterações.
